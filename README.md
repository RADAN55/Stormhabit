# Storm Habit — How a Habit Is Built

Interactive 90-minute EL lesson (grades 9–12, ELPA21 Levels 3–4) for Week 13, Tuesday, at Laurel High School. Part of the Storm Studio / EL Publishing resource ecosystem.

**Live page:** https://radan55.github.io/stormhabit/

What's inside: bell ringer, sketchpad, hook poll, habit lab, video with autograded checks, read-aloud passage with self-checking stop-and-jots, vocabulary notebook and matching game, grammar move (when/after/once/until), "Rebuild a habit" planner, five ELPA21-style test prep items with audio, ELPA21-aligned writing rubric, O·R·E·A·C exit ticket, progress bar, and a full report sent to Jotform.
